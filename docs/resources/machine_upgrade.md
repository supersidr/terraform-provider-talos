# talos_machine_upgrade (Resource)

The machine upgrade resource allows you to upgrade Talos on a node.

## Example Usage

```terraform
resource "talos_machine_upgrade" "this" {
  node = "10.5.0.2"

  client_configuration = {
    ca_certificate     = "base64-encoded-ca"
    client_certificate = "base64-encoded-client-certificate"
    client_key         = "base64-encoded-client-key"
  }

  image       = "ghcr.io/siderolabs/installer:v1.10.0"
  reboot_mode = "default"
  stage       = false
  force       = false
  preserve    = false
  wait        = true
}
```

### Optional

- `endpoint` (String) The endpoint of the node to upgrade. Defaults to `node`.
- `force` (Boolean) Force upgrade by skipping safety checks.
- `image` (String) The installer image to use for upgrade.
- `preserve` (Boolean) Preserve machine data during upgrade.
- `reboot_mode` (String) Reboot mode to use during upgrade (`default`, `powercycle`).
- `stage` (Boolean) Stage the upgrade and apply after reboot.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))
- `wait` (Boolean) Wait for the upgrade action to complete and node to become ready.
